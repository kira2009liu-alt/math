高中数学学习助手｜可安装手机桌面的 PWA 版本

文件：
- index.html：应用主体
- manifest.webmanifest：应用名称、图标和独立窗口配置
- sw.js：离线缓存
- icon-192.png / icon-512.png：桌面图标

安装说明：
1. 将这 5 个文件放到同一个 GitHub 仓库的根目录（不要只上传 index.html）。
2. 在仓库 Settings → Pages 中启用 GitHub Pages，选择部署分支和 /(root)。
3. 等待 Pages 发布，打开 GitHub Pages 给出的 https://...github.io/... 地址。
4. 用 Android Chrome 打开网页，点右上角 ⋮，选择“安装应用”或“添加到主屏幕”。
5. 安装后桌面会出现“高中数学学习助手”图标，点击图标即可像普通应用一样打开。

注意：
- 必须通过 HTTPS 网页地址安装；直接点手机里的 HTML 文件不能安装成带图标的 PWA。
- 首次打开需要联网完成安装和缓存；之后应用页面可离线打开。
- 数据仍保存在当前浏览器/应用站点的本机存储中。不要清除该站点数据，定期使用应用内“数据管理”导出备份。
- 图片/大量记录会占用手机浏览器存储空间。
